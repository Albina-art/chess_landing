# Club Landing

Простой лендинг с версткой на HTML/CSS/JS.

## Структура

- `index.html` — основная разметка страницы
- `styles.css` — стили и адаптив
- `script.js` — интерактив (слайдеры, анимации и т.п.)
- `images` — все картинки

## Запуск

Откройте `index.html` в браузере или используйте любой локальный сервер.

Пример с Python:

```bash
python3 -m http.server 8000
```

После запуска откройте [http://localhost:8000](http://localhost:8000).
